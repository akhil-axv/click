# Signal Studio

A minimal, responsive traffic signal simulator built with vanilla HTML, CSS, and JavaScript.

## Features

- Clean dark interface with responsive layout
- Interactive red, yellow, and green signal states
- Automatic signal sequence with pause and reset controls
- Accessible state labels and keyboard-friendly controls
- No frameworks, dependencies, or build tools

## Run locally

Open `index.html` in any modern browser.

## Deploy

Enable GitHub Pages for this repository and select the default branch as the source.

## Note

This is an educational visual demo only. It does not connect to or control real traffic infrastructure.
